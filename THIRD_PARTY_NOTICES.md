# Third-Party Notices

SkillPath currently contains no copied or adapted third-party source or curriculum
content. It depends on open-source packages and container images listed in
`DEPENDENCIES.md`; their upstream license texts and notices remain authoritative.

Before distribution, generate and archive dependency and image SBOMs, retain any
notices required by the selected artifacts, and review code and content/data licenses
separately. Update this file whenever code, content, fonts, images, models, datasets,
or dependencies with attribution requirements are adopted.

The researched tutor and graph projects in
`docs/research/OPEN_SOURCE_ADOPTION.md` are references or future spike candidates;
none of their code or content is included in this repository.
